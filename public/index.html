How multiplayer works

Tekken 3

Both players run OpenKumite with matching game data. A Matchbox room introduces the browsers over WebRTC. Each simulates the fight locally and corrects earlier frames when inputs arrive late.

Road Rash

Both riders run the PC rework locally and join the same race server. The host creates a room in Mano a Mano and shares the invite code. Each rider has their own view.

These are unofficial community projects. Each project retains its credits and notices.
